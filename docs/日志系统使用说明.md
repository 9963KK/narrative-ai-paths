# 日志系统使用说明

## 概述

本项目已经实现了统一的日志管理系统，可以有效控制控制台输出的详细程度，避免在生产环境中产生过多的日志信息。

## 功能特性

### 1. 日志级别控制
- **ERROR**: 只显示错误信息
- **WARN**: 显示警告和错误信息  
- **INFO**: 显示信息、警告和错误
- **DEBUG**: 显示所有日志信息（开发环境默认）
- **SILENT**: 不显示任何日志

### 2. 环境自适应
- 开发环境：默认显示所有日志（DEBUG级别）
- 生产环境：默认只显示警告和错误（WARN级别）

### 3. 可视化控制面板
- 右下角的日志控制面板，可以实时调整日志级别
- 支持一键重置和页面刷新
- 可以隐藏/显示控制面板

## 使用方法

### 在代码中使用日志函数

```typescript
import { devLog, devInfo, devWarn, devError, perfLog, apiLog, stateLog, authLog, dbLog, routeLog } from '@/utils/logger';

// 基础日志
devLog('这是一条调试信息');
devInfo('这是一条信息');
devWarn('这是一条警告');
devError('这是一条错误信息');

// 分类日志
perfLog('性能监控信息');
apiLog('API调用信息');
stateLog('状态变化信息');
authLog('认证相关信息');
dbLog('数据库操作信息');
routeLog('路由变化信息');
```

### 通过控制面板调整日志级别

1. 在页面右下角找到日志控制面板（📝 图标）
2. 点击展开面板
3. 选择合适的日志级别
4. 点击"刷新页面"使设置生效

### 通过代码调整日志级别

```typescript
import { setLogLevel } from '@/utils/logger';

// 设置为静默模式
setLogLevel('SILENT');

// 设置为只显示错误
setLogLevel('ERROR');

// 设置为显示所有日志
setLogLevel('DEBUG');
```

### 通过浏览器控制台调整

```javascript
// 设置日志级别
window.setLogLevel('SILENT');

// 查看当前日志级别
window.getLogLevel();
```

## 配置说明

### localStorage 配置项

- `app_log_level`: 存储当前的日志级别设置
- `show_log_control`: 控制是否显示日志控制面板

### 环境变量影响

- `import.meta.env.DEV`: 开发环境标识
- `import.meta.env.PROD`: 生产环境标识

## 最佳实践

### 1. 选择合适的日志级别
- 使用 `devError` 记录错误信息
- 使用 `devWarn` 记录警告信息
- 使用 `devInfo` 记录重要的状态信息
- 使用 `devLog` 记录调试信息

### 2. 使用分类日志函数
- 认证相关：使用 `authLog`
- API调用：使用 `apiLog`
- 性能监控：使用 `perfLog`
- 状态变化：使用 `stateLog`
- 数据库操作：使用 `dbLog`
- 路由变化：使用 `routeLog`

### 3. 生产环境优化
- 在生产环境中，建议设置为 `WARN` 或 `ERROR` 级别
- 避免在生产环境中输出敏感信息
- 定期检查和清理不必要的日志输出

## 故障排除

### 1. 日志不显示
- 检查当前日志级别设置
- 确认是否设置为 `SILENT` 模式
- 尝试刷新页面

### 2. 控制面板不显示
- 开发环境下应该自动显示
- 生产环境需要手动设置 `localStorage.setItem('show_log_control', 'true')`

### 3. 设置不生效
- 确保在设置后刷新了页面
- 检查浏览器的localStorage是否正常工作

## 扩展功能

如需添加新的日志分类，可以在 `src/utils/logger.ts` 中添加新的日志函数：

```typescript
export const customLog = (message: string, ...args: any[]) => {
  if (shouldLog(LOG_LEVELS.DEBUG)) {
    console.log(`🔧 [CUSTOM] ${message}`, ...args);
  }
};
```

## 注意事项

1. 日志级别设置会保存在localStorage中，跨会话保持
2. 更改日志级别后需要刷新页面才能生效
3. 在生产环境中，过多的日志输出可能影响性能
4. 敏感信息不应该通过日志输出
