# AI故事生成问题诊断指南

## 🔍 问题症状
- 故事生成的内容看起来像预设文本而非AI生成
- 界面显示"用户模型配置失败，请联系管理员"
- 但同时又能看到一些故事内容和"正在生成选择项..."

## 🎯 可能原因分析

### 1. API密钥问题 (最可能)
- ✅ 已配置Deepseek模型
- ❌ API密钥可能无效、过期或权限不足
- ❌ API密钥格式不正确

### 2. 积分余额不足
- 即使配置正确，积分不足也会导致AI调用失败
- 系统会回退到备用内容生成

### 3. 网络连接问题
- API调用超时或网络不稳定
- 导致部分请求失败

## 🛠️ 解决步骤

### 步骤1: 检查API密钥
1. 前往 **设置页面**
2. 检查Deepseek模型的API密钥配置
3. 确认密钥格式：`sk-xxx...` 
4. 尝试重新输入API密钥

### 步骤2: 验证API密钥有效性
在Deepseek官网：
1. 登录你的Deepseek账户
2. 检查API密钥状态
3. 确认有足够的配额余额
4. 如果需要，重新生成新的API密钥

### 步骤3: 检查积分余额
1. 在系统中查看当前积分余额
2. 如果积分不足，需要充值或联系管理员

### 步骤4: 浏览器控制台诊断
1. 按F12打开开发者工具
2. 切换到"控制台"标签
3. 重新生成故事
4. 查看是否有具体的错误信息

### 步骤5: 清除缓存重试
1. 刷新页面
2. 清除浏览器缓存
3. 重新登录
4. 再次尝试生成故事

## 🔧 临时解决方案

如果问题持续存在，可以：

1. **尝试其他AI模型**: 在设置中切换到其他可用的AI提供商
2. **联系管理员**: 确认系统配置和API密钥池状态
3. **使用简单模式**: 临时使用简化的故事生成避免复杂的AI调用

## 📊 调试信息收集

请收集以下信息以便进一步诊断：

1. **浏览器控制台错误信息**
2. **当前使用的AI模型和提供商**
3. **积分余额信息**
4. **最后一次成功生成故事的时间**

## 💡 预防措施

1. **定期检查API密钥状态**
2. **监控积分余额**
3. **保持API密钥的安全性**
4. **及时更新过期的配置**
